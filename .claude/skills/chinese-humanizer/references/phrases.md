# 高频 AI 味词库与替换建议

## 一、空泛连接词（直接删，或换成口语词）

| AI 写法 | 怎么处理 |
|---|---|
| 首先 / 其次 / 再次 | 删。用「第一件事是」「还有一个」或直接不写 |
| 综上所述 / 总而言之 / 归根结底 | 删，或换成「说白了」「总之」 |
| 值得注意的是 / 值得一提的是 | 删，把要说的重点直接写出来 |
| 众所周知 / 不难发现 | 删。真众所周知就不用写，不众所周知就别装 |
| 随着……的发展 / 在……的背景下 | 删，从具体事件开头 |
| 与此同时 / 与此同时 | 换成「同时」「而且」 |
| 不仅如此 / 更重要的是 | 换成「更狠的是」「还有个坑是」 |

## 二、装腔词（语境不符就删，别解释）

赋能、闭环、抓手、沉淀、颗粒度、底层逻辑、顶层设计、痛点、打法、布局、生态位、齐头并进、双轮驱动、行稳致远、躬身入局、破圈、拉通、对齐、打透、引爆、放大（×100 倍）、天花板、降本增效、数字化、智能化（滥用时）。

**注意**：这些词在真正的技术/商业写作里可以保留（比如「API 闭环」「数据沉淀」有实义），只在它们只是撑场面时删。

## 三、AI 句式特征

- 每段结尾总结句：「……至关重要」「……不可或缺」「这体现了……的重要性」
- 自问自答：「那么，如何做到呢？」「答案是肯定的」
- 三连排比：「让用户更高效、更便捷、更安全」
- 过度对仗：「既能……又能……还能……」
- 「我们坚信 / 我们始终 / 我们致力于」
- 头尾呼应式完美结构（每篇都是）

## 四、替换思路速查

| 想表达 | 不要写 | 改写方向 |
|---|---|---|
| 效果好 | 效果显著 | 具体到数字/对比/结果 |
| 有诚意 | 我们高度重视 | 描述你做了什么动作 |
| 有规划 | 制定了详细的规划 | 列出接下来具体几件事 |
| 有信心 | 充满信心 | 说一句你凭什么这么想 |
| 很专业 | 专业的服务 | 举个例子展示你专业在哪 |

## 五、保留原则

技术名词、法律/合同措辞、官方正式函件里的固定用语，**不要**强行口语化。工具是「该人话的地方人话，该正式的地方正式」。
